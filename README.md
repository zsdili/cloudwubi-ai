# CloudWubi AI — 云端智能引擎

> 面向 5G/6G 的云原生五笔输入法 · AI 组件
> 上下文感知排序 + 云端词库自动训练 · 纯 Python 标准库 · 免费可离线

## 简介

CloudWubi AI 是 CloudWubi 的**云端智能大脑**，兑现"越用越准、无限输入"的核心价值：

| 能力 | 模块 | 说明 |
| ---- | ---- | ---- |
| 上下文感知排序 | `ai_context.py` | 根据已上屏的上文，预测下一个高概率候选（智能联想） |
| 云端词库自动训练 | `ai_trainer.py` | 从用户行为日志发现高频新词，自动建议入词库 |
| 模型持久化 | 内置 | 2-gram 模型可云端共享、增量更新 |

## 设计原则（先科学、后先进）

1. **先科学**：基于 2-gram 马尔可夫统计模型——输入法智能联想的经典可靠方案，微秒级推理、零API成本、可离线运行
2. **后先进**：预留大模型接口层，未来可无缝接入 OpenAI 兼容端点（云端大模型增强）
3. **免费优先**：当前阶段零成本运行，符合"公共免费资源优先"原则
4. **可扩展**：训练语料可来自用户行为日志、社区贡献、公开语料，支持持续学习

## 快速开始

```bash
# 1. 上下文感知排序
python3 ai_context.py
# 期望：上文"云计算" → 候选"平台"置顶

# 2. 词库自动训练
python3 ai_trainer.py
# 期望：从用户日志发现高频新词（如"算力"）

# 3. 单元测试
python3 test_ai_engine.py
# 期望：6 项测试全部通过
```

## 架构

```
用户输入序列（已上屏词）
    ↓
ai_context.predict(context_words, candidates)
  1. 取上文末词
  2. Bigram 条件概率 P(候选|上文)
  3. 高概率候选置顶
    ↓
返回智能排序后的候选

用户行为日志（云端）
    ↓
ai_trainer.ingest() → discover_new_words()
  1. 统计高频词
  2. 过滤已收录/低频/超窗
  3. 导出新词建议 + 训练语料
    ↓
云端审核 → 并入规则库（社区共建）
```
